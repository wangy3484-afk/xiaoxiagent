# 14.2 黄金场景自动验收记录

执行日期：2026-10-04。测试：`backend/tests/integration/test_generated_golden_reports.py`，命令：`python -m pytest -q backend/tests/integration/test_generated_golden_reports.py`，结果：通过。

12 个匿名黄金场景均通过生产 LangGraph 报告图，使用确定性模型、搜索、抓取和提取测试提供商生成独立报告。四类运营场景各 3 份；交付状态与黄金基准一致：4 份正式报告、7 份方向性草案、1 份失败说明。草案和失败说明没有被标记为正式报告。

自动门槛逐份核验完整章节、来源覆盖、主张与证据引用、行动闭环、指标口径、资源约束、禁止自动执行、主场景策略、基线状态和交付状态。每个预期阻断项均在专业审查结构化结果中出现；受阻场景经过最多两轮质量修订后按受限状态交付。批量入口还拒绝缺失、额外、损坏和重复报告 ID；运行方式见 [质量评审手册](quality-review-manual.md#8-十二场景自动验收)。

这是离线结构与规则验收。确定性测试提供商的脚本化审查不等于真实模型的专业判断；真实供应商预发布测试和运营专家七维盲评分别保留在 14.3、14.5。
